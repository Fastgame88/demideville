# DEMI DEVILLE — готовий сайт + адмінка

Сайт зібраний за наданими макетами ПК/телефон. Архів містить фронтенд, локальний Node.js сервер, реєстрацію/вхід, корзину, checkout, збереження замовлень і CMS-адмінку.

## Що реалізовано

- Головна сторінка з окремим desktop/mobile фоном.
- SHOP з товарами з адмінки.
- Картка товару: фото, ціна, розміри, Details/Fabric/Size/Delivery, Add To Bag, Buy Now.
- Корзина: кількість, видалення, підсумок.
- Checkout: контактні/адресні поля, способи оплати у дизайні, створення замовлення.
- Реєстрація та логін користувача; паролі зберігаються у вигляді scrypt-хешів.
- Gallery та About.
- Повністю адаптивна мобільна версія та меню.
- Адмінка: тексти, шрифти, логотип/назва, фон ПК/телефон, login-art, контакти, Instagram, доставка, валюта.
- CRUD товарів: назва, ID, ціна, фото, опис, тканина, розміри, сортування, видимість.
- CRUD Gallery.
- Кастомні додаткові розділи/сторінки.
- Завантаження фото прямо з адмінки.
- Список замовлень і зміна статусу.
- Зміна пароля адміністратора.
- Дані зберігаються локально у `data/db.json` — окрема БД для локального запуску не потрібна.

## Швидкий запуск на Windows

1. Встановіть **Node.js 18+** з офіційного сайту Node.js, якщо його ще немає.
2. Розпакуйте архів у будь-яку папку, наприклад `C:\demi-deville-site`.
3. Подвійний клік по `start.bat` або відкрийте CMD/PowerShell у папці сайту та виконайте:

```bat
node server.js
```

4. Відкрийте у браузері:

```text
http://localhost:3000
```

Адмінка:

```text
http://localhost:3000/admin
```

## Початковий вхід в адмінку

```text
Email: admin@demideville.local
Password: Admin123!
```

Після першого запуску зайдіть в **Security** і змініть пароль.

## Запуск на macOS / Linux

```bash
chmod +x start.sh
./start.sh
```

або:

```bash
node server.js
```

## Як редагувати сайт

Відкрийте `/admin` → **Site settings**. Тут можна змінювати назву бренду, заголовок, desktop/mobile фон, Login background/art, About, контакти, Instagram, шрифти, базовий розмір шрифту, валюту та доставку.

У **Products** можна додавати/редагувати/видаляти товари. Фото можна вставити URL або завантажити з комп'ютера. Розміри вводяться через кому: `XS, S, M, L, XL`.

У **Custom sections** можна створювати нові сторінки. Наприклад: title `Lookbook`, slug `lookbook`, контент і фото. На мобільному новий розділ автоматично з’явиться в меню. URL сторінки: `/section.html?slug=lookbook`.

## Де зберігаються дані

- Контент/товари/користувачі/замовлення: `data/db.json`
- Фото, завантажені через адмінку: `public/uploads/`
- Початкові зображення з макету: `public/assets/images/`
- Стилі: `public/assets/css/`
- JS фронтенду: `public/assets/js/`

Перед великими правками просто зробіть копію `data/db.json` і `public/uploads/`.

## Важливо про оплату

Кнопки PayPal / Apple Pay / Google Pay / Crypto / Card відтворені у checkout та вибирають спосіб оплати, але **реальний платіжний шлюз не підключений**. При натисканні `Review order` сайт створює замовлення в адмінці. Для приймання реальних грошей треба окремо підключити Stripe/PayPal/LiqPay/WayForPay/інший провайдер і його API/webhooks.

## Для продакшену

Поточна збірка максимально проста для локального запуску без npm-пакетів і зовнішньої БД. Перед публічним запуском бажано винести дані в PostgreSQL/MySQL, поставити HTTPS/reverse proxy, SMTP для листів, реальний payment provider і резервні копії.
